# План: Возможность задать свой вопрос в режиме «Интервью»

Цель: дать пользователю возможность задать свой вопрос агенту в режиме **Интервью** (chat) вместо получения случайного вопроса из RAG.

Статус: ✅ Реализовано.

---

## 1) Контекст и текущее состояние

Режим «Интервью» (chat) работает так:
1. На монтировании вызывается `chatApi.getRandomQuestion()` → рандомный вопрос из RAG.
2. Пользователь пишет ответ в textarea → «Отправить».
3. Запрос `POST /api/chat` → ответ ассистента в формате Markdown.
4. Кнопка «Сохранить в Word» сохраняет `lastQuestion` + `lastAnswer` в docx.
5. Кнопка «Следующий вопрос» сбрасывает state и грузит новый случайный вопрос.

Бэкенд `/chat` уже умеет обрабатывать любые вопросы и возвращает `meta.suggest_save` если вопрос не из docx.

---

## 2) Что добавлено

1. **Кнопка «Задать свой вопрос»** на экране чата.
2. **Режим ввода своего вопроса** — отдельный блок с textarea.
3. **Кнопки «Получить ответ» / «Отмена»** в режиме custom.
4. После получения ответа — стандартный блок с ответом ассистента + «Сохранить в Word».

Backend не изменялся — `/chat` уже поддерживает любые вопросы.

---

## 3) Архитектура (реализация)

### `useChat.ts`

Новые состояния:
- `customQuestion: string` — текст своего вопроса
- `isCustomMode: boolean` — флаг режима "свой вопрос"

Новые хендлеры:
- `setCustomQuestion(value)` — обновляет `customQuestion`
- `enterCustomMode()` — переключает в режим ввода своего вопроса
- `cancelCustomMode()` — возвращает в обычный режим (с рандомным вопросом)
- `submitCustomQuestion()` — отправляет свой вопрос в `/chat`, результат записывается в `lastQuestion`/`lastAnswer`

### `presentation.tsx`

- Если `isCustomMode=true` → показывается блок ввода своего вопроса вместо карточки с рандомным вопросом
- Если `isCustomMode=false` → обычный режим с рандомным вопросом + кнопка «Задать свой вопрос»
- После ответа на свой вопрос — стандартный вывод (ответ ассистента, кнопки «Сохранить в Word», «Следующий вопрос»)

### `index.tsx`

Пробрасываются новые пропсы:
- `customQuestion`, `isCustomMode`
- `onCustomQuestionChange`, `onEnterCustomMode`, `onCancelCustomMode`, `onSubmitCustomQuestion`

## 4) UX-flow

1. Пользователь на экране «Интервью» → видит рандомный вопрос.
2. Под блоком вопроса → новая кнопка **«Задать свой вопрос»**.
3. Клик → режим ввода: textarea + «Получить ответ» / «Отмена».
4. Ввод вопроса → «Получить ответ».
5. Ответ ассистента появляется ниже.
6. Кнопка «Сохранить в Word» доступна для сохранения пары вопрос/ответ в docx.
7. Кнопка «Следующий вопрос» → загрузка нового случайного вопроса.
